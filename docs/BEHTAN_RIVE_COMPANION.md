# همراه به‌تن — Rive

این نسخه جایگزین بستهٔ تصویری قبلی است. مبنای پچ `099f5e7` از `main` است و نصب بستهٔ قبلی لازم نیست.

## فایل‌ها

- `public/mascot/behtan-companion.riv`: فایل واقعی Rive، artboard با نام `Behtan` و state machine با نام `Companion`.
- `public/mascot/behtan-rest.svg`: همان هندسه در حالت ثابت؛ برای کاهش حرکت یا خطای بارگذاری.
- `design/behtan-companion/scene.rml`: منبع قابل ویرایش Rive؛ شامل بردارها، گرادیان‌ها، کی‌فریم‌ها و ماشین حالت.
- `design/behtan-companion/build_scene.py`: تولیدکنندهٔ قابل بازسازی منبع، بدون وابستگی پایتونی.
- `src/components/companion`: اتصال React، راهنمای موقعیتی و استایل.
- `companion-preview.html` و `previews/`: ورودی بازبینی؛ وارد بیلد اصلی یا ادمین نمی‌شود.

این کاراکتر بازطراحی برداری ۲.۵بعدی از کانسپت تأییدشده است؛ فایل مدل سه‌بعدی نیست. حجم با گرادیان‌های ثابت، سایه‌های موضعی و ترتیب اجزا ایجاد می‌شود. چشم، پلک، دهان، دست‌ها و بدن جداگانه حرکت می‌کنند؛ تصویر رستری متحرک در `.riv` وجود ندارد.

## قرارداد کنترل

View model: `Companion`، instance: `Default`؛ مقادیر عددی:

| property | مقدار | رفتار |
|---|---|---|
| mode | 0 | تنفس بسیار آرام و پلک‌زدن |
| mode | 1 | سلام با حرکت مستقل دست |
| mode | 2 | توجه با خم‌شدن ملایم |
| mode | 3 | فکرکردن با دست نزدیک بدن |
| mode | 4 | تشویق کوتاه با هر دو دست و تغییر لبخند |
| mode | 5 | همراهی آرام با دست روی سینه |
| mode | 6 | اشاره برای قدم بعدی |
| mode | 7 | استراحت با چشم‌های نیمه‌بسته |
| gazeX | −7 تا +7 | جابه‌جایی محدود چشم‌ها به افق |
| gazeY | −5 تا +5 | جابه‌جایی محدود چشم‌ها به عمود |

React حالت‌های گذرا را به idle برمی‌گرداند. حرکت بعد از حدود ۱۲٫۵ ثانیه سکون متوقف می‌شود؛ لمس، تغییر حالت یا حرکت نشانگر دوباره آن را فعال می‌کند. فایل خام نیز listener لمس برای سلام دارد؛ در React غیرفعال است تا دکمهٔ HTML هم‌زمان لمس و کیبورد را بدون رویداد تکراری پوشش دهد.

## رفتار در محصول

- لندینگ: سلام و واکنش به لمس؛ CTA و مسیر ورود قبلی حفظ شده‌اند.
- آنبوردینگ: راهنمای همان مرحله، واکنش توجه هنگام تمرکز روی ورودی؛ مرحلهٔ پزشکی آرام می‌ماند. هنگام ارسال، حالت فکرکردن.
- داشبورد: تشویق فقط پس از resolve شدن ذخیرهٔ وعده؛ بارگذاری سوابق، لغو ثبت و خطا تشویق نمی‌گیرند. انتخاب جایگزین واکنش راهنمایی دارد.
- پروفایل: حضور آرام کنار بخش روند؛ هیچ استنتاج پزشکی از وزن انجام نمی‌شود.
- وضعیت‌های ایمنی، محاسبات تغذیه، پرداخت و ساختار دیتابیس تغییر نکرده‌اند.

## اجرا و هزینهٔ بارگذاری

Runtime قفل‌شده: `@rive-app/canvas@2.44.2`؛ با import پویا و WASM میزبانی‌شده در همان اپ. هیچ CDN، درخواست Rive API یا ارسال اطلاعات کاربر برای انیمیشن وجود ندارد.

- خود فایل کاراکتر: ۹٬۱۶۹ بایت.
- موتور WASM: حدود ۲٫۰۶ مگابایت قبل از فشرده‌سازی HTTP؛ مستقل از فایل کاراکتر و قابل کش است.
- chunk جاوااسکریپت runtime: حدود ۲۸۳ کیلوبایت خام / ۷۳ کیلوبایت gzip.
- در حالت کاهش حرکت runtime بارگذاری نمی‌شود.
- خارج از دید یا در تب مخفی، instance پاک‌سازی می‌شود؛ بازگشت دوباره آن را می‌سازد. بارگذاری موتور در همان نشست مشترک است.
- تراکم پیکسل canvas حداکثر ۲، بدون نورپردازی زنده، mesh سه‌بعدی، texture یا shader.

تست مرورگر دسکتاپ و شبیه‌سازی viewport انجام شده؛ سنجش روی گوشی فیزیکی ضعیف هنوز انجام نشده است. پخش روی دستگاه واقعی را پیش از انتشار نهایی بررسی کنید.

## ویرایش و بازسازی Rive

Rive CLI نسخهٔ 1.6.0 استفاده شده است. نصب مطابق مستندات رسمی https://rive.app/docs/cli/getting-started انجام شود. برای استفاده از پچ نصب CLI لازم نیست: `.riv` آماده داخل پچ است.

```bash
python3 design/behtan-companion/build_scene.py
rive design/behtan-companion --verify
rive inspect design/behtan-companion --summary
rive design/behtan-companion --once
cp design/behtan-companion/build/behtan-companion.riv public/mascot/behtan-companion.riv
```

فایل هیچ اسکریپت داخلی ندارد؛ اجرای وب آن به امضای اسکریپت نیاز ندارد. برای گرفتن فایل editable با پسوند `.rev` و بازکردن در Editor، مطابق مقررات Rive وارد حساب خود شوید و از قابلیت export همان CLI استفاده کنید. این بسته فایل `.rev` جعلی یا فایل سه‌بعدی ندارد.

`build_scene.py` منبع اصلی است؛ اجرای دوبارهٔ آن تغییرات دستی `scene.rml` را بازنویسی می‌کند. ابتدا تغییر را در تولیدکننده اعمال کنید، سپس verify و inspect و رندر بصری را انجام دهید.

## بازبینی محلی

```bash
npm ci
npm run dev -- --host 0.0.0.0
```

پورت 5173 را باز و مسیر `/companion-preview.html` را به آدرس اضافه کنید. برای HTML مستقل:

```bash
npm run export:companion-preview
```

خروجی در `preview-export/behtan-rive-preview.html` است؛ همهٔ فونت‌ها، فایل Rive و runtime داخل آن‌اند. نمونه‌های آنبوردینگ و روزمره برای تست واکنش‌اند و به حساب/دیتابیس وصل نیستند. طراحی آن نمونه‌ها جایگزین کامل صفحات اصلی نمی‌شود؛ پچ فقط حضور همراه را به صفحات فعلی اضافه می‌کند.
