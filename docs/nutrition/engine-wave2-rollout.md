### سرور ایران

فقط فایل migration مربوط به مرحلهٔ جاری را از شاخهٔ بررسی‌شده به مسیر /opt/behtan/migration/ انتقال بده. پس از بکاپ و تأیید، در نشست SSH اجرا کن.

```bash
cd /opt/behtan/supabase
docker compose exec -T db psql -U postgres -d postgres -v ON_ERROR_STOP=1 \
  < /opt/behtan/migration/20261105171239_048_nutrition_context_snapshot.sql
```

در مرحلهٔ 049، همین دستور را با فایل 20261105172329_049_authoritative_member_meals.sql اجرا کن. اجرای SQL باید با COMMIT تمام شود. این دو migration از CI به production اعمال نمی‌شوند.

### بررسی 048 در SQL Editor استودیوی ایران

```sql
begin;
set local role service_role;
with snapshot as materialized (select public.nutrition_context_snapshot() as value)
select value->>'revision' as revision,
       jsonb_array_length(value->'food_rows') as foods,
       jsonb_array_length(value->'slot_rows') as slots,
       value->'policy_row'->>'id' as policy
from snapshot;
rollback;
```

revision باید مقدار داشته باشد، تعداد غذا و slot مثبت باشد و policy برابر default باشد.

## قرارداد فعلی API سرور

مسیر /api/member با action برابر meal_schedule و نشست کاربر دارای اشتراک. درخواست read شامل kind و date است. درخواست‌های generate، rotate و swap علاوه بر روز، requestId، catalogRevision، intakeRevision و expectedUpdatedAt می‌گیرند. ورودی generate شامل workout و regenerate است. rotate فقط slot می‌گیرد. swap شامل slot، componentIndex، foodId و units انتخاب‌شده است. سرور مقدار پیشنهادی را دوباره محاسبه می‌کند. روز مجاز از امروز تهران تا شش روز بعد است.

درخواست تکراری با همان شناسه و محتوا تا ۲۴ ساعت نتیجه ثبت‌شده را برمی‌گرداند. پس از تعارض STALE_CONTEXT، STALE_INTAKE یا STALE_PLAN ابتدا وضعیت تازه دریافت شود. مسیر قدیمی می‌تواند برنامه را بازنویسی کند ولی اعتبار ذخیرهٔ سرور را از آن سطر می‌گیرد. تا انتقال تمام جریان‌های عضو و لغو دسترسی legacy، این API مسیر انحصاری تجویز نیست.

## E04b و دادهٔ مورد نیاز

تست مصنوعی، مجموعهٔ ۱۵ غذا را برای شروع بازبینی مشخص کرده است. عدس پخته، سیب‌زمینی آب‌پز، خیار و گوجه، روغن زیتون، شیر کم‌چرب، جو دوسر، موز، گوشت چرخ‌کرده کم‌چرب، برنج سفید پخته، سالاد، سیب، ماهی، سینه مرغ، ماست کم‌چرب و خرما. شناسهٔ دقیق هر ردیف در scripts/allergen-safety.test.mjs است.

با فرض مصنوعی بازبینی این ردیف‌ها، هر سه ترکیب حساسیت در روز تمرین و استراحت برنامه، جایگزین عضو و گزینه پرو داشتند. برای انتشار داده واقعی، برای هر ردیف شکل عرضه یا دستور، منبع معتبر اجزا، وضعیت تماس متقاطع و تأیید بازبین لازم است. تا رسیدن آن شواهد، وضعیت تولید برای داده نامعلوم بسته می‌ماند.
