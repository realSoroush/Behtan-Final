# پچ تکمیلی آنبوردینگ به‌تن

این پچ برای به‌روزرسانی همان PR شمارهٔ ۲۱ ساخته شده است. نسخهٔ مبنا، commit `a3409805b0202be870cd032ee320dcc20bc45aa7` در شاخهٔ `feature/member-app-final` است. این بسته فقط تغییرات تکمیلی آنبوردینگ را دارد؛ پچ بازطراحی قبلی را دوباره اجرا نکن.

## تغییرات

- ورود، کد تأیید و همهٔ مراحل فعال آنبوردینگ با رنگ، فونت، کارت و دکمهٔ هماهنگ با اپ اعضا طراحی شده‌اند؛ حالت روشن و تاریک دارند.
- در دسکتاپ راهنما کنار فرم است؛ در موبایل، شخصیت به‌تن و سه بخش کلی بالای فرم قرار می‌گیرند. شمارنده همچنان ۱۰ مرحلهٔ واقعی را نشان می‌دهد.
- جهت حرکت رفت و برگشت درست شده، عنوان مرحله برای کیبورد و صفحه‌خوان قابل دسترس است و تنظیم کاهش حرکت رعایت می‌شود.
- قد و وزن، شماره موبایل و کد تأیید، عدد فارسی و عربی را می‌پذیرند. وزن اعشاری هم درست ثبت می‌شود.
- استان تکراری حذف و کردستان اضافه شده است. برای شهرهای خارج فهرست، نام واقعی شهر وارد می‌شود. انتخاب جنسیت دیگر شهر را پاک نمی‌کند.
- خطای دریافت پروفایل به شروع دوبارهٔ فرم تبدیل نمی‌شود؛ کاربر می‌تواند دریافت اطلاعات قبلی را دوباره امتحان کند.
- گزینهٔ «ادامه بدون عکس» از ابتدای مرحله در دسترس است. در مسیر بدون عکس، کارت‌های عددی نامشخص نمایش داده نمی‌شوند.
- پیش از انتخاب اشتراک، خلاصهٔ قد، وزن و هدف دیده می‌شود. قیمت و شرایط واقعی اشتراک همچنان از Supabase دریافت و پیش از پرداخت بررسی می‌شوند.
- فیلدهای فرم هنگام ذخیره غیرفعال می‌شوند. ذخیره قبل از رفتن به مرحلهٔ بعد، بررسی پزشکی و رضایت پردازش عکس حفظ شده‌اند.

## ۱. روی شاخهٔ همان PR برو

فایل ZIP را بیرون مخزن استخراج کن. `$bundle` باید پوشه‌ای باشد که `Apply-Onboarding-Update.ps1` داخل آن است. اگر `git status` تغییر ذخیره‌نشده نشان داد، اول آن را جداگانه ذخیره کن. این اسکریپت روی مخزن دارای تغییر اجرا نمی‌شود.

```powershell
cd E:\Behtan-Final
git status --short
git switch feature/member-app-final
git pull --ff-only origin feature/member-app-final
$bundle = "$env:USERPROFILE\Downloads\behtan-onboarding-polish-v1"
powershell -NoProfile -ExecutionPolicy Bypass -File "$bundle\Apply-Onboarding-Update.ps1" -Repo "E:\Behtan-Final"
```

اسکریپت ابتدا سازگاری پچ را بررسی می‌کند. اگر خطا داد، ادامه نده و خروجی خطا را نگه دار. هیچ push یا deploy خودکاری انجام نمی‌شود.

## ۲. تست و Build

وابستگی جدیدی اضافه نشده است. اگر `node_modules` فعلی سالم است، نیازی به نصب دوباره نیست؛ در غیر این صورت `npm ci` را اجرا کن. CI پروژه Node.js 24 دارد.

```powershell
node --experimental-strip-types scripts/onboarding-experience.test.mjs
node --experimental-strip-types scripts/onboarding-activity-split.test.mjs
npm run test:onboarding
npm run test:body-scan
npm run test:medical-safety
npm run test:subscriptions
npm run test:production
npm run build
npm run dev
```

برای دیدن فرم واقعی، با یک حساب آزمایشی که هنوز آنبوردینگ را کامل نکرده وارد شو. حساب تکمیل‌شده طبق روال قبلی مستقیم وارد داشبورد می‌شود؛ دادهٔ حساب اصلی‌ات را برای تست پاک نکن.

این موارد را بررسی کن:

۱. انتخاب شهر، سپس انتخاب جنسیت، نام شهر را حفظ کند.

۲. وزن `۱۲۵٫۵` و قد `۱۷۸` پذیرفته شوند. دادهٔ نامعتبر دکمهٔ ادامه را غیرفعال کند.

۳. بعد از زدن ادامه و موفقیت ذخیره، Refresh همان مرحلهٔ بعد را باز کند. در خطای ذخیره، فرم جلو نرود.

۴. بررسی پزشکی همچنان جلوی صدور برنامهٔ خودکار برای وضعیت‌های مسدود را بگیرد.

۵. مسیر بدون عکس، بدون درخواست دوربین یا تحلیل هوش مصنوعی تا اشتراک ادامه پیدا کند.

۶. مراحل، متن‌ها و دکمه‌ها در موبایل و حالت تاریک خوانا باشند و اسکرول افقی نداشته باشند.

تست‌های مرورگر دسکتاپ و موبایل هم به مجموعهٔ فعلی اضافه شده‌اند:

```powershell
npx playwright install chromium
npm run test:public:browser
```

