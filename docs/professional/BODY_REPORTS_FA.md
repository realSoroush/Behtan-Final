# گزارش تصویری بدن و اصلاح تجربه پنل

مبنای پچ: main با commit `2b47055b1732ea245090033af725b1de403f3d8a`، پس از مرج PR 16.

## چه تغییر کرده؟

- مدیریت فضای کاری و ساخت حساب در ادمین، اشتراک و ظرفیت در Pro و مشاهده/ذخیره برنامه در مودال باز می‌شوند. بازگشت فوکوس، Escape، قفل اسکرول و دراپ‌داون داخل مودال پشتیبانی می‌شوند. هنگام عملیات فعال، بستن با Escape یا دکمه بسته است.
- پایان اعتبار و تعلیق مجوز یا فضای کاری: مشاهده پرونده، تاریخچه، برنامه ذخیره‌شده و PDF باز؛ ایجاد/ویرایش، تولید برنامه، بایگانی، تحلیل جدید و پیوست جدید بسته. لغو عضویت همچنان دسترسی را قطع می‌کند. درخواست تمدید برای مالک باز است و پرداخت انجام نمی‌دهد.
- در پرونده ذخیره‌شده: «تحلیل تصویری بدن و گزارش‌ها». یک تا سه نمای جلو، کنار، پشت؛ اندازه‌های اختیاری دور کمر، دور باسن و درصد چربی اندازه‌گیری‌شده همراه روش سنجش.
- گزارش: قد/وزن ثبت‌شده، BMI، نسبت‌های محاسبه‌شده، کیفیت تصاویر و، فقط در صورت ورود درصد چربی اندازه‌گیری‌شده، جرم چربی و توده بدون چربی. توده بدون چربی معادل عضله نیست.
- بازبینی و تأیید گزارش الزامی است. از پنجره یک برنامه ذخیره‌شده، گزارش تأییدشده همان نسخه اطلاعات را انتخاب و متصل کنید. در PDF بعدی، پیوست در صفحه جدا پس از رژیم درج می‌شود. پیوند ثبت‌شده تغییرناپذیر است؛ برنامه جدید می‌تواند پیوست دیگری داشته باشد.
- فرمول رژیم، کاتالوگ، ماکروها، PlanPreview و فایل قالب قبلی PDF تغییر نکرده‌اند. بدون پیوست، HTML رژیم دقیقاً از همان قالب قبلی تولید می‌شود.

## این قابلیت اسکن سه‌بعدی واقعی نیست

نمونه پیوست‌شده خروجی دستگاه BIA است. عکس معمولی داده امپدانس، آب بدن، چربی احشایی، سن زیستی یا توده عضله تولید نمی‌کند. این نسخه عمداً چنین عددهایی نمی‌سازد. هوش مصنوعی فقط کیفیت ثبت تصاویر را بررسی می‌کند؛ اندازه‌ها و نسبت‌ها از ورودی ثبت‌شده محاسبه می‌شوند و روی کالری رژیم اثر ندارند. برای هندسه سه‌بعدی یا اندازه‌گیری دور اندام از عکس، یک سرویس تخصصی معتبر و آزمون مستقل لازم است؛ این بسته آن فناوری را ادعا نمی‌کند.

مدل پیشنهادی برای راه‌اندازی فنی: `gpt-4.1-2025-04-14` با Responses API، ورودی تصویر و خروجی JSON محدود. مدل از متغیر سروری قابل تغییر است. این انتخاب تضمین دقت بالینی یا نتیجه مقایسه زنده مدل‌ها نیست. مسیر Gemini آنبوردینگ B2C در این نسخه تغییر نکرده است.

## ۳. تنظیم Vercel

فقط پروژه `behtan-pro`، Environment Variables برای محیط انتشار:

```text
PRO_BODY_SCAN_ENABLED=true
OPENAI_API_KEY=<کلید حساب API شما>
PRO_BODY_SCAN_MODEL=gpt-4.1-2025-04-14
```

تنظیم‌های موجود VITE_SUPABASE_URL، VITE_SUPABASE_ANON_KEY و SUPABASE_SERVICE_ROLE_KEY همان پروژه حفظ شوند. کلید OpenAI نباید VITE_ داشته باشد، در git ثبت شود یا در چت ارسال شود. حساب API باید دسترسی و اعتبار مدل انتخاب‌شده را داشته باشد. پس از تنظیم، Redeploy لازم است. بدون این تنظیم، رژیم و PDF معمولی کار می‌کنند؛ تحلیل جدید پیام غیرفعال‌بودن سرویس می‌دهد. برای خاموش‌کردن تحلیل جدید، PRO_BODY_SCAN_ENABLED را false و Redeploy کنید؛ گزارش‌های ذخیره‌شده همچنان قابل مشاهده‌اند.

## ۵. تست دستی

1. یک پرونده مصنوعی ثبت کنید؛ اندازه‌ها و رژیم/PDF معمولی را بررسی کنید.
2. از «تحلیل تصویری بدن و گزارش‌ها» یک تا سه عکس مناسب با رضایت مراجع انتخاب کنید. عکس اسناد یا گزارش دستگاه، جای عکس بدن نیست.
3. اندازه‌های اختیاری را وارد کنید. درصد چربی بدون روش سنجش پذیرفته نمی‌شود.
4. گزارش را بازبینی کنید؛ سپس تأیید کنید. اگر کیفیت عکس نامناسب گزارش شد، برای مقایسه آتی عکس مناسب‌تری ثبت کنید.
5. یک برنامه ذخیره‌شده همان نسخه اطلاعات را باز کنید، گزارش را از «پیوست گزارش بدن» متصل کنید و PDF بگیرید.
6. پس از ذخیره، قطع ارتباط و تلاش مجدد را بررسی کنید؛ نتیجه قبلی باید برگردد و پیوست تکراری ایجاد نشود.
7. از ادمین، مجوز را منقضی یا معلق کنید؛ Pro باید سوابق/PDF را باز و ساخت/ویرایش را بسته نگه دارد. سپس اعتبار را بازگردانید.

## حریم خصوصی و محدودیت‌های عملیاتی

- عکس در مرورگر به JPEG با حداکثر ضلع 1280 تبدیل می‌شود؛ EXIF/GPS و نام فایل ارسال نمی‌شود. هر عکس ورودی تا 12MB، تا سه عکس و درخواست نهایی حداکثر 3.5MB است.
- عکس‌ها به OpenAI ارسال می‌شوند و در دیتابیس، Storage، PDF، localStorage یا لاگ به‌تن ذخیره نمی‌شوند. فایل اصلی نزد کاربر باقی می‌ماند. متن رضایت ارائه‌دهنده و نگهداری جداگانه را روشن می‌گوید.
- `store:false` به‌معنی Zero Data Retention تضمین‌شده نیست. سیاست نگهداری و شرایط پردازش حساب API باید پیش از استفاده با داده سلامت واقعی بررسی شود. تست محلی بسته با تصاویر مصنوعی است؛ عکس پیوست واقعی برای API ارسال نشده.
- تصاویر برای تشخیص بیماری، تخمین درصد چربی یا تغییر خودکار رژیم استفاده نمی‌شوند. تأیید متخصص جای اعتبارسنجی علمی ابزار را نمی‌گیرد.
- تنها گزارش، اندازه‌ها، نسخه ورودی و رضایت نسخه 1 ذخیره می‌شود؛ سابقه تأیید و پیوست تغییرناپذیر است. گزارش تکمیل‌شده قابل بازنویسی نیست.
- برای هر فضای کاری 20 درخواست جدید در ساعت و برای هر درخواست حداکثر 3 تلاش؛ پردازش همزمان همان درخواست مسدود، نتیجه تکمیل‌شده در retry بازگردانده می‌شود. اگر پردازش به علت قطع سرور نامعلوم بماند، اجاره پس از 90 ثانیه قابل بازیابی است. ممکن است در timeout ارائه‌دهنده، یک تلاش محاسباتی دوباره هزینه داشته باشد؛ ثبت گزارش نهایی همچنان یکتا است.
- فهرست گزارش‌ها 30 گزارش اخیر پرونده را نشان می‌دهد؛ پیوست برنامه‌های قدیمی مستقل از این فهرست قابل دریافت است.
