# گزارش آزمون نسخه 030 — پنل ماژولار Pro

مبنا: 67c44b1؛ تاریخ بررسی 2026-10-22. تمام داده‌های آزمون مصنوعی‌اند. در این مرحله به Supabase اصلی یا کاربران واقعی متصل نشدیم و چیزی روی GitHub/Vercel منتشر نکردیم.

## نتایج اجراشده

- test:pro: موفق؛ شامل ۵۷۴ ترکیب منوی مستقل، قراردادهای UI و پرونده، سرویس ساخت برنامه، حساب Pro، گزارش بدن، بکاپ، ماژول‌های runtime و بررسی schema بازیابی.
- SQL واقعی روی PGlite: ۳۹۴ بررسی، شامل Migration 030، مجوز ادمین، قیمت عمومی بدون دسترسی به جدول، هم‌زمانی با revision، تکرار درخواست، جلوگیری از دورزدن ماژول، جداسازی سازمان‌ها، تعلیق با حفظ خواندن، پرونده خارج از دامنه سنی موتور و snapshot اختصاصی immutable.
- test:training: ۴۳۲ ترکیب معتبر و ۱۴۶٬۹۳۵ assertion موتور مشترک؛ ۷۴ بررسی HTTP.
- test:pro:modules: ۲۹۴ بررسی اضافی؛ یک تا هفت روز، روزهای متوالی و تقسیم برنامه، زمان جلسات، بیماری/دارو، کش و دستگاه بدون دمبل، نبود سطر تکراری، حفظ گیت B2C و escaping خروجی اختصاصی.
- تست‌های مرورگر Pro: ۸۲ مورد روی دسکتاپ و موبایل، موفق.
- تست‌های مرورگر ادمین: ۲۲ مورد روی دسکتاپ و موبایل، موفق.
- تست صفحه عمومی: ۴ مورد روی دسکتاپ و موبایل، موفق؛ انتخاب دوره، قیمت کل دوره، خطای شبکه و retry، کنترل overflow و بررسی تصویری تم روشن/تیره.
- پس از آخرین تغییرات، ۴۰ تست مرتبط Pro و ۴ تست عمومی دوباره موفق اجرا شدند.
- test:production، test:admin، test:onboarding، test:medical-safety، test:age و test:routing موفق.
- build، build:admin و build:pro موفق؛ برای بیلد واقعی Pro، VITE_PRO_SANDBOX_ENABLED=true بود.
- قالب PDF تغذیه قبلی تغییر نکرده است. مسیرهای PDF و برنامه‌های قبلی در تست مرورگر باقی مانده‌اند. PDF تدوین اختصاصی جداگانه و با escaping متن بررسی شد.

## محدودیت‌های بررسی

- تست native PostgreSQL 17 و بازیابی dump در این محیط اجرا نشد؛ مسیر CI موجود آن‌ها را با Migration جدید اجرا خواهد کرد. PGlite جای بازیابی واقعی بکاپ نیست.
- دانلود Chromium پیش‌فرض Playwright در محیط ساخت ناقص بود؛ آزمون‌ها با Chromium 133 و PRO_BROWSER_EXECUTABLE انجام شدند. dependency یا lockfile پروژه برای این جایگزین تغییر نکرد.
- هشدار حجم bundle ادمین و Pro وجود دارد؛ بیلد موفق است.
- آزمون مرورگر با API مصنوعی انجام شده؛ فعال‌سازی روی Supabase/Vercel و تست نهایی زنده پس از Migration لازم است.
- تدوین اختصاصی متنی است و اعداد واردشده را به محاسبات خودکار کالری/ماکرو یا تجویز پزشکی تبدیل نمی‌کند.
- پرداخت آنلاین، دعوت پیامکی و اتصال بیمار به اپ در این نسخه اضافه نشده‌اند.
