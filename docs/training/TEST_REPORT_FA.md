# گزارش واقعی آزمون موتور تمرینی

تاریخ: ۲۰۲۶-۱۰-۲۲. داده‌ها مصنوعی؛ هیچ کاربر یا پرونده سلامت Production برای تست خوانده یا تغییر داده نشده است.

| بررسی | نتیجه |
|---|---|
| ترکیب‌های موتور | ۴۳۲ برنامه معتبر با سابقه، هدف، زمان، روزها، تجهیزات خانه/باشگاه و جثه‌های متفاوت |
| شرط‌های خودکار موتور | ۱۴۶٬۹۳۵ بررسی در اجرای تست؛ شامل تکرارپذیری، تجهیزات، تاریخ واقعی جلسه، استراحت، دامنه ورودی، توقف ایمنی، زمان و خروجی HTML. این تعداد assertion است، نه تعداد افراد یا کارآزمایی |
| مرز HTTP تمرین | ۷۴ بررسی با HTTP واقعی محلی و وابستگی کنترل‌شده: ورود، تزریق plan/actor، متد، سایز، CSRF، لاگ بدون داده شخصی و تکرار درخواست |
| کل دیتابیس Pro | ۳۵۳ بررسی روی PostgreSQL تعبیه‌شده PGlite؛ نقش‌ها، RLS/grant، جداسازی، تغییرناپذیری، ظرفیت، آرشیو، تکرار و سقف ساخت تمرین |
| مرورگر Pro | ۷۸ سناریو، دسکتاپ و موبایل، موفق؛ ۱۲ مورد مربوط به تمرین و بقیه regression مسیرهای موجود |
| مرورگر ادمین | ۱۸ سناریو، دسکتاپ و موبایل، موفق |
| API پس از کامپایل | تست‌ها روی گراف JS خروجی بدون فایل TS هم موفق؛ importهای سرور Vercel بررسی شدند |
| build | B2C، Admin و Pro موفق؛ build پنل Pro با VITE_PRO_SANDBOX_ENABLED=true نیز اجرا و حضور UI و API تمرین در bundle بررسی شد؛ تولید رسمی موتور سمت سرور باقی است؛ typecheck سرور موفق |
| regression B2C | test:production، test:nutrition، test:medical-safety، test:meal-progress، test:onboarding و test:admin موفق |
| PDF | نمونه فارسی مصنوعی ۶ صفحه A4 با Chromium رندر شد؛ تصاویر و QR بارگیری شدند؛ صفحات شروع، جدول و راهنما تصویری بررسی شدند |
| patch | سازگاری دو مسیر نصب از main مرجع و از بسته ۰۲۸ با git apply و مقایسه بایت فایل‌ها بررسی شد |

## اصلاح‌هایی که آزمون پیدا کرد

- برچسب تجهیزات پارویی با کش با GIF ناسازگار بود؛ نیاز نیمکت و راهنمای فارسی اصلاح شدند.
- نمونه لت پیچیده با نسخه نشسته و دستگیره موازی جایگزین شد.
- روزهای پایان/ابتدای هفته هم از نظر فاصله تمرین کنترل شدند؛ تاریخ هر جلسه اکنون به تاریخ شروع متصل است.
- بستن سریع پنجره چاپ می‌توانست Promise آماده‌سازی تصاویر را معلق نگه دارد؛ تشخیص بسته‌شدن پنجره و مهلت ۱۵ ثانیه‌ای اضافه شد. تست مرورگر این رفتار و آزادشدن پنل را بررسی می‌کند.
- assertion قدیمی تست اشتراک، متن قبل از ۰۲۸ را انتظار داشت؛ با رفتار فقط‌خواندنی فعلی هم‌راستا شد.

## مرز نتیجه

- این‌ها تست نرم‌افزارند؛ کارآزمایی یا تأیید علمی/بالینی مستقل نیستند. بازبینی اجرای تمرین توسط مربی و تست کاربری واقعی هنوز باید انجام شوند.
- PostgreSQL مستقل، PostgREST واقعی Supabase، JWT واقعی Production و بازیابی بکاپ Production در این محیط اجرا نشدند. CI موجود، تست native PostgreSQL 17 و dump/restore مصنوعی را برای اجرای GitHub دارد؛ نتیجه اجرای بعدی CI هنوز معلوم نیست.
- نخستین دانلود Chromium پیش‌فرض Playwright در این محیط فایل ناقص داد؛ مرورگر جایگزین Chromium 134 با PRO_BROWSER_EXECUTABLE استفاده شد. نسخه dependency یا lockfile پروژه برای دورزدن این مشکل تغییر نکرد.
- تست‌های مرورگر از سرور Vite و پاسخ‌های کنترل‌شده استفاده می‌کنند. مرز HTTP و SQL جداگانه تست شده‌اند؛ اتصال نهایی در Supabase/Vercel پس از Migration باید با یک پرونده مصنوعی اجرا شود.
- پچ روی GitHub push یا روی Vercel منتشر نشده است؛ هیچ Migration روی Supabase اصلی اجرا نشده است.
